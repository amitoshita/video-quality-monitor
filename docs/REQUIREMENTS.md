# Requirements checklist

Every requirement of the task, where it is implemented, and how it is verified. Paths are relative to the repository root. "Unit" = vitest/pytest, "e2e" = `e2e/run.mjs` (real app, headless Chrome, fake camera, run in CI), "manual" = the browser checklist in [DEPLOY.md](DEPLOY.md), done with a real camera on the public URL.

## 1. Live screen

| Requirement                                                                      | Implementation                                                                                                                                                                                                    | Verified by                                                                                        |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Ask for the camera on Start; 640×480, front camera                               | `frontend/src/pipeline/camera.ts` `openCamera`, `VIDEO_CONSTRAINTS` (`ideal` 640×480, `facingMode: "user"`), called from `LiveSession.start`                                                                      | e2e `live` (camera opens at 640×480); manual                                                       |
| Denied permission or no camera: clear message, no crash or blank page            | `toCameraError` maps every `getUserMedia` error to a human message; `LiveSession.start` shows it and returns to idle                                                                                              | unit `camera.test.ts`, `session.test.ts`; e2e `denied` (message shown, no session created); manual |
| Camera preview on screen                                                         | `frontend/src/ui/LiveScreen.tsx` `<video>`, mirrored with CSS only                                                                                                                                                | e2e; manual                                                                                        |
| Process every frame: draw to a canvas, read the pixels, with rVFC or rAF         | `frontend/src/pipeline/frameLoop.ts` `startFrameLoop` (requestVideoFrameCallback; rAF fallback skips repeated frames); `frontend/src/pipeline/analyzer.ts` `FrameAnalyzer.process` (`drawImage` + `getImageData`) | unit `frameLoop.test.ts`; e2e `live` ("frames come from requestVideoFrameCallback")                |
| Optional downscale to 160×120                                                    | `frontend/src/metrics/luma.ts` `ANALYSIS_WIDTH/HEIGHT`                                                                                                                                                            | unit `luma.test.ts`                                                                                |
| Once per second, combine the frames into one sample (averages)                   | `frontend/src/pipeline/aggregator.ts` `SecondAggregator`; `frontend/src/metrics/aggregate.ts` `aggregateSecond`                                                                                                   | unit `aggregator.test.ts`, `aggregate.test.ts`                                                     |
| FPS = frames actually processed in that second                                   | `aggregateSecond`: `fps = totals.frames` (frames counted in `addFrame`; failed frames aren't counted)                                                                                                             | unit; e2e `live` (20 fps from Chrome's 20 fps fake camera, 30 from the 30 fps video files)         |
| Brightness = mean of 0.299R + 0.587G + 0.114B, 0–255                             | `computeLuma`                                                                                                                                                                                                     | unit (black 0, white 255, pure R/G/B, gradient); e2e `dark` (0.0), `bright` (255.0)                |
| Motion = mean absolute luma difference to the previous frame                     | `meanMotion`; first frame and post-gap frames give no value instead of 0                                                                                                                                          | unit; e2e `motion` (noise feed flagged)                                                            |
| Face: is at least one face in the frame (any library)                            | `frontend/src/pipeline/faceDetector.ts` MediaPipe BlazeFace; the second's `face` is true if any frame had one                                                                                                     | unit `aggregate.test.ts`, `session.test.ts`; manual (real face)                                    |
| Face is detection only, no liveness / anti-spoofing                              | Not built, by design; README "Known limitations"                                                                                                                                                                  | —                                                                                                  |
| Thresholds listed in the README                                                  | README "Thresholds" (values, comparison, env var, motion calibration)                                                                                                                                             | —                                                                                                  |
| Verdict every second: Good only if all four metrics are within limits, else Poor | `frontend/src/metrics/verdict.ts` `computeVerdict` (inclusive limits)                                                                                                                                             | unit `verdict.test.ts` (each reason, every boundary)                                               |
| When Poor, show which metric ("Poor: too dark")                                  | `frontend/src/ui/MetricsPanel.tsx`, `format.ts` `verdictText`, `metrics/reasons.ts`                                                                                                                               | unit `format.test.ts`; e2e; manual                                                                 |
| Live chart: last 30 s, updated every second                                      | `frontend/src/ui/QualityCharts.tsx` / `TimeChart.tsx` (uPlot, `setData` in place)                                                                                                                                 | e2e; manual                                                                                        |
| FPS, brightness, motion as lines; face and verdict as colored strips             | Three stacked line charts sharing one time window; `StatusStrip.tsx` (green ✓ / red ✕ with text labels)                                                                                                           | manual; screenshots during development                                                             |
| Start creates a session, opens the camera, starts sending                        | `LiveSession.start` (camera first, then `POST /sessions`; see README "Start order")                                                                                                                               | unit `session.test.ts`; e2e                                                                        |
| Stop closes the camera, sends the last samples, ends the session                 | `LiveSession.stop`: camera off at once, queue drains in the background, then `POST /stop`                                                                                                                         | unit; e2e `live`, `startStop`, `stopOffline`                                                       |
| Closing the tab without Stop is fine; the session ends at its last sample        | `pagehide` → keepalive send of pending samples, deliberately no `/stop`; summary duration = last `t`                                                                                                              | unit `session.test.ts` (pagehide), backend `test_summary.py` (no stop)                             |

## 2. Backend

| Requirement                                                                                                                                  | Implementation                                                                                                                                                                    | Verified by                                                                                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST /sessions` → id and started_at                                                                                                         | `backend/app/routes.py` `create_session` → `repository.create_session`                                                                                                            | `test_sessions.py`; smoke test                                                                                                                                        |
| `POST /sessions/{id}/samples` saves a list                                                                                                   | `ingest_samples` → `repository.ingest_samples`                                                                                                                                    | `test_samples.py`; smoke                                                                                                                                              |
| `POST /sessions/{id}/stop` saves ended_at                                                                                                    | `stop_session` → `repository.stop_session`                                                                                                                                        | `test_sessions.py`; smoke                                                                                                                                             |
| `GET /sessions`: newest first, each with summary                                                                                             | `list_sessions` → `repository.list_sessions` (one LEFT JOIN + GROUP BY, paginated)                                                                                                | `test_sessions.py`, `test_summary.py`; smoke                                                                                                                          |
| `GET /sessions/{id}`: all samples plus summary                                                                                               | `get_session` → `repository.get_session_detail` (samples ordered by `t`)                                                                                                          | `test_sessions.py`; smoke                                                                                                                                             |
| Sample shape `{t, fps, brightness, motion, face, verdict, reason}`                                                                           | `backend/app/schemas.py` `SampleIn` (strict, no extra fields, finite numbers)                                                                                                     | `test_validation.py`                                                                                                                                                  |
| `t` = seconds since start                                                                                                                    | `SecondAggregator` (first completed second is `t = 1`; README)                                                                                                                    | unit `aggregator.test.ts`                                                                                                                                             |
| `reason` = first failing metric in the order no face, too dark/bright, hold still, low FPS; null when Good                                   | `computeVerdict`; backend enforces "reason null exactly when Good" (`SampleIn` + DB check constraint)                                                                             | unit `verdict.test.ts`; `test_validation.py`                                                                                                                          |
| Summary by the backend: duration = last `t`, average FPS, % face, % Good                                                                     | `repository._summary_columns` / `_to_summary` (null stats for empty sessions, half-up rounding)                                                                                   | `test_summary.py`                                                                                                                                                     |
| Send small batches about every 1–2 s                                                                                                         | `frontend/src/pipeline/sampleQueue.ts` (flush every 1.5 s, ≤120 per batch)                                                                                                        | unit `sampleQueue.test.ts`, `session.test.ts`                                                                                                                         |
| Validate input; bad data → 4xx with a clear JSON error (missing fields, FPS outside 0–120, brightness/motion outside 0–255, unknown session) | `schemas.py`; `backend/app/errors.py` (one envelope for every error); malformed/unknown id → 404                                                                                  | `test_validation.py` (26 invalid cases, NaN/Infinity, malformed JSON), `test_sessions.py`, `test_http.py`; smoke                                                      |
| On a failed request the browser keeps the samples and resends them; none lost or saved twice; `(session id, t)` unique                       | Client: queue removes samples only after a 2xx, retries with backoff, resends at once when back online. Server: `(session_id, t)` primary key + `INSERT … ON CONFLICT DO NOTHING` | unit `sampleQueue.test.ts`; `test_samples.py` (resend, overlapping batches, in-batch duplicates); e2e `offline` (10 s outage → contiguous `t`, no duplicates); manual |
| Stop called twice: no error, no duplicate data                                                                                               | `repository.stop_session` (`UPDATE … WHERE ended_at IS NULL`; repeat returns the same `ended_at`)                                                                                 | `test_sessions.py`; smoke                                                                                                                                             |
| Samples arriving after Stop: no error, no duplicate data; choice explained                                                                   | 200 with `ignored_after_stop`, not stored (README "Design decisions")                                                                                                             | `test_samples.py`; smoke                                                                                                                                              |
| CORS only from the frontend's address, from configuration                                                                                    | `backend/app/main.py` `CORSMiddleware` with `CORS_ORIGINS` from `config.py` (no wildcard)                                                                                         | `test_http.py`; smoke (allowed vs. other origin)                                                                                                                      |
| Real database; data survives a restart                                                                                                       | Postgres on Neon in production (SQLite file locally), schema by Alembic migration                                                                                                 | `test_migrations.py`; CI runs the suite on Postgres 17                                                                                                                |

## Rules

| Rule                                                                              | How it is met                                                                                                                                                                                                   | Verified by                                                                         |
| --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Video never leaves the browser; only numbers are sent                             | Frames exist only in a canvas in memory; the only request bodies are sample JSON (`frontend/src/api/client.ts`); model and wasm served from our own origin                                                      | README "Privacy"; code review of `client.ts`                                        |
| Real numbers only; FPS measured, not from camera settings; "No face" when no face | FPS = frames processed; unmeasured values are `null` (shown as "—"), never invented; a session can't start without the face detector, so "no face" always means a face was looked for                           | unit; e2e                                                                           |
| No hard-coded settings; `.env.example`                                            | Backend: `pydantic-settings`, thresholds required with no code defaults (`config.py`), `backend/.env.example`. Frontend: `VITE_API_BASE_URL` only (thresholds come from `GET /config`), `frontend/.env.example` | `test_http.py` (fails fast without config); build fails without `VITE_API_BASE_URL` |
| Free only                                                                         | See Deploy                                                                                                                                                                                                      | —                                                                                   |
